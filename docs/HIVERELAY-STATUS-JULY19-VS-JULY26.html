July 26

Federation quorum receipts merged (7 commits). Multi-relay cross-verification is now on main. The 2-relay substrate cutover is deploying. The "GA gate" is no longer code — it's operator recruitment and the boot-restore fix (in progress now).

Cutover in progress

July 19

"Tor transport is experimental (a documented fail-open gap is being closed before any 'location anonymity' claim)."

Tor RA-01 through RA-07 fully implemented, tested (5/5 test suites pass), and merged to main. RA-06 (Docker + Umbrel packaging with pinned tor 0.4.9.x sidecar) shipped today. Code complete · needs live integration test against real Docker deploy

July 19

"PVSS custody is computational (not post-quantum), proven as a mechanism; the independent-operator fleet run is the remaining gate."

→
July 26

Local shard cohort merged (3 commits) — BlindShard dispersal can now be tested end-to-end with a fake cohort locally. The code path is proven; the independent-operator fleet run remains the deployment gate.

Code done · gated on operators

July 19

"Writer pubkeys are enumerable (needed for sync)."

→
July 26

Still true for today's OutboxLog. The blind substrate cutover (in progress) addresses this at G2-S (storage-schema opacity — no app/author/community in stored state). Once converged, writer enumeration is defeated.

Being fixed by substrate cutover

5. IP + timing not hidden

July 19

"IP + timing at the relay/gateway are not hidden by the architecture — Tor is the mitigation path, not the default."

→
July 26

Tor is now packaged and deployable (docker compose --profile tor up -d), but still opt-in, not default. Split transport (OHTTP for browsers, Protomux for native) is fully spec'd with dev-profile approval — targets G2-W + G4-T. Not yet built.

Tor: deployable · Split transport: spec'd
